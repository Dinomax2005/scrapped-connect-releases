# First run

Open Lately and choose **Create your account**. Enter your name, a unique username, email address, and password. Supabase sends a confirmation link; follow it to activate the account and return to Lately. If the link doesn’t start your session automatically, log in with the same email and password.

Your profile and activity are stored in the shared Lately Social backend, so the same email and password work on another device. You can edit your profile, change your password, or request a reset link from the sign-in screen.

The first feed includes fictional sample people and posts. They’re there to make the first visit feel lived-in; accounts you create are real Supabase users. Configure a custom SMTP sender in Supabase before inviting more than a few testers, since the default mail sender is for development.
